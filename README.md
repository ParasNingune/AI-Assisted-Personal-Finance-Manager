# AI-Assisted Personal Finance Manager

A smart, AI-powered personal finance manager that helps you track
expenses, set budgets, and get data-driven insights to save more
effectively.

## 📖 About

AI-Assisted Personal Finance Manager is a full-stack web application
designed to help users gain better control of their finances using AI.

## ✨ Features

-   Expense tracking
-   Budget creation
-   AI-driven categorization
-   Savings insights
-   Dashboard visualizations

## 🛠 Tech Stack

-   Frontend: JavaScript, HTML, CSS
-   Backend: Node.js
-   Database: MongoDB
